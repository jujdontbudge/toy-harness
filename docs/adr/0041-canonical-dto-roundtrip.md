# ADR 0041: Canonical R0 TypeScript and Python DTO boundaries

AT-hermes-config-50 requires the specified RunContext actor, distinct decimal revision/generation/sequence/watermark values, FocusSession.focusGeneration, and an exact UTF-8 observation quote. Attention ownerId and cycleId are separate domain fields. Hermes §5.1 and Activity-Focus §§5.2–5.3 already supply the public interfaces; this unit publishes those interfaces through the existing contracts inventory and generator.

PrincipalId and PermissionRef remain aliases of UUID, as specified. The generator emits those aliases from the canonical primitive alias inventory rather than creating duplicate schemas. RunContext, FocusSession and IngestReceipt reject unknown fields and reuse the existing UUID, Revision, UInt64String, Instant, Digest and ObservationEvidenceRef schemas. Observation offsets must be paired and have a document; reversed offsets are refused. The JSON schemas preserve the paired-field requirement. The retained-document ownership and quote verification remain Life Store responsibilities.

The existing public ReplayEnvironment.runRegisteredProbe operation dispatches one unfiltered source-bound AT-hermes-config-50 manifest to a fixed DTO diagnostic. Its eight observations use the public TypeScript schemas, the real isolated Python interpreter and generated Python TypedDict/NewType representations. Python round-trips only synthetic fixed DTOs. It reports representation preservation, not runtime validation by TypedDict. There is no additional product command, composite wire DTO, service, provider or storage owner.

The diagnostic requires an owned ready R0 fake-clock/fake-model stack and records exact counter and quote readbacks in bounded CheckViews. Malformed UUIDs, numeric/noncanonical decimal counters, UInt64 overflow, unknown fields, missing span partners and missing documents are refused through the public schemas. Run/show receipts and complete owned-stack teardown are required. No private-function test or internal collaborator mock is introduced.

This source unit has a two-hour limit beginning 2026-10-06T23:26:00Z and stops after its assigned CLI diagnostic passes or three failures. Full principal-to-actor resolution remains pending on protected identity.principals. Actual Client tool consumption, immutable retained Life evidence and the Swift DTO round-trip remain pending; Swift generation and compilation are deferred to R3. RunAdmission/TurnReview ownership and actual seven-day capacity arms remain separate prerequisites. Whole AT and release acceptance remain incomplete.
