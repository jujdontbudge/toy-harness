# Bootstrap resource preflight

Status: implementation contract for measured prerequisites. No runtime permit, heavy lease, aggregate enforcement, signed execution or whole acceptance is established.

Ops owns one internal `measureBootstrapResources` implementation. It hides OS acquisition, exact byte decoding, real monotonic sample spacing, deadline handling and conservative predicates. The existing public `OpsControlRead.doctor` exposes its safe summary when `deep:true`; the CLI remains a thin adapter. The registered `bootstrap.resource-admission` check is reused. Installed service/owner probes remain in the denominator, non-null owner transport results stay unavailable and no service health is inferred from the host measurement. Future runtime admission must consume this same measured component, with independently admitted lease/enforcement/artifact/identity checks.

Three snapshots are separated by at least 500 real milliseconds. The minimum free bytes across the snapshots must meet both 1.5 decimal GB and the provisional 1,024 MiB aggregate ceiling plus 512 MiB margin; the larger threshold is 1,610,612,736 bytes. Physical fit uses the conservative non-free physical complement plus that threshold, and rejects a free counter exceeding physical RAM. Merely fitting the ceiling alone into the Mac's RAM cannot establish fit beside the existing workload. This conservative complement is not per-process footprint or full runtime capacity evidence. `os.freemem()` uses the exact pinned Node/libuv Darwin free counter times page size. It includes no added active/inactive/anonymous estimate and does not add speculative pages again. `process.availableMemory()` is diagnostic only because its pinned Darwin implementation adds reclaimable inactive/purgeable counters. All counters must be safe nonnegative integers before canonical UInt64String encoding; unavailable values remain null.

Pressure uses a fixed read-only `sysctl -n kern.memorystatus_vm_pressure_level` request. Apple XNU converts its internal enum to dispatch flags before export; only exact 1/2/4 decode as normal/warning/critical. The masked sysctl is not a documented stable public pressure-query API. Missing, malformed, unsupported or unknown output remains unknown and blocks a future permit. This is not a claim that current upstream source attests the running kernel build.

Swap uses the fixed binary `sysctl -b vm.swapusage` read, decoded only for the current Darwin arm64 little-endian ABI. Installed SDK `struct xsw_usage` contains three UInt64 counters followed by UInt32 page size and Boolean: total, available, used, page size, encrypted. Exactly 32 bytes and consistent total/available/used counters are required. Formatted MiB strings are not a byte oracle. Neither total allocated swap nor used swap may grow across any adjacent sample; the maximum reports positive growth of either counter. Partial/unknown samples cannot establish stability. This one-second observation window is a bounded startup preflight, not a trial, soak, peak-capacity or full runtime stability verdict.

Every OS subprocess has a fixed executable/argv, minimal environment, ignored stdin, bounded output and timeout within the owner's real deadline. Raw stdout/stderr is discarded after allowlisted decoding. No identity, path, endpoint, pressure override, expected result or resource budget comes from a CLI argument. No filesystem/account/provider/model/service change occurs.

The generated private preflight records snapshots, conservative minimum, provisional ceiling/margin, measured predicates, finite reasons and `resourcePermitIssued:false`. Its admission state is always blocked while the real heavy-work owner and aggregate process enforcement are absent. Doctor shows only a bounded safe numeric/enum summary; it neither writes the request journal nor issues a capability. A short command timeout returns incomplete measurements with a timeout reason rather than pretending the interval completed.

Acceptance for this increment is through compiled packed `toy doctor --deep`: preserve the complete missing-service inventory, add the registered blocked resource check, show measured bytes/pressure/swap or explicit unknown, remain incomplete/exit 5, discard raw diagnostics, and honor a short real timeout. Private functions are not tested. Registered external OS fault cases, lease contention/death, pressure loss, failed suspension, all-descendant enforcement, exact signing and actual-identity denials remain prerequisites for executable admission and full AT-cli-3/4/9/10.
