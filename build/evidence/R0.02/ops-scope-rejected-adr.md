# Ops research component scope

`EngineeringControl.checkResearch` keeps its existing input, return type, CLI route, report formats, and V1–V3 inspection schemas. Its existing `specReferences` readback already contains the canonical `specs/ops.md` component IDs and source lines. The research owner derives an internal `ResearchOpsRequirementScopeV1` by joining those references to the parsed `RESEARCH-REGISTER.md` component inventory and reading the canonical `specs/README.md` requirement-to-spec table.

The scope contains the README and Ops source paths/digests plus each joined component ID, its Ops source lines, and its applicable requirement IDs. The Ops source list is complete: unmapped component references remain visible in the existing `COMPONENT_REFERENCE_UNMAPPED` findings and do not silently create a register component. The requirement table is recognized by its `Req` and `Spec(s)` columns. For AT-ops-43's required IDs `0.1`, `0.2`, `0.10`, `2.4`, and `5.10`, the spec cell applies to Ops when it names `ops` or `all`; duplicate rows, missing required rows, malformed target rows, or rows no longer mapped to Ops fail closed.

Every joined Ops component receives those source-derived Ops IDs in addition to its current comparator requirements. Shared components such as M02 and M03 remain in the generic Ops component scope when referenced by `ops.md`. Existing non-Ops comparison behavior remains intact: Sources still adds `0.9`, and its account, region, route, and skill checks remain; dedicated Attention decisions keep their existing requirements and route predicates; Authority-specific decision and acceptance predicates remain. The existing `componentDecisions` array continues to cover the register without changing its ordering or shape. `compareDecision` still returns provisional predicate findings only.

The derived scope is an internal typed value of the existing engineering owner, validated by its canonical `@toy/contracts` schema but not returned by `checkResearch`. It is not a new CLI, inspection DTO, module, or admission permit. `ResearchRegisterInspectionV3` remains unchanged, with `admission: BLOCKED`, `dependencyClosureVerified: false`, `researchAttestationVerified: false`, `acceptanceComplete: false`, and an empty `wholeATsPassed`. This source change neither supplies decision records nor attests primary evidence, the protected research route/account, a component build denial, AT-ops-43/44, or whole release acceptance.
